# Returns — the index

A return is a question back to a brief's author that the implementer cannot answer: a verdict gate that
proves unmeasurable, a brief that assumes something the code contradicts, an ownership question the
roadmap cannot settle. **A return blocks, it does not decide**: it records the evidence, lists the options
with their costs, states a recommendation, and says plainly what has *not* been done. Nothing moves until
a ruling comes back. The rules are in [`CLAUDE.md`](../../CLAUDE.md) §Returns.

Every return has **one mark** here, set once, when it is ruled:

| Mark | Means |
|---|---|
| 🔲 open | waits on the owner; the item it names is blocked |
| ✅ ruled | the ruling is recorded in the return's own header; the item moved |
| ⛔ closed | overtaken — the item was retired or the question dissolved; the return stays as the record |

A return's file is `<item>-<what-it-asks>.md`, and its header carries: **was · now · why · not-done ·
scope · before-or-after the check ran**.
